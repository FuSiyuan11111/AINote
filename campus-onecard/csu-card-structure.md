## 中南大学校园卡现状：一账户多介质与国密CPU卡
- 2026-09-21

**结论**：2022 年一卡通三期升级后，中南校园卡 = **后台一卡通账户 + 多种介质**（实体国密 CPU 卡、手机 NFC 模拟卡、微信校园卡二维码，食堂终端另支持人脸/扫码/刷卡三合一）。官方未公布芯片型号，但 2022 年采购「国密密钥管理系统 V2.0 + 金融加密机」可推断现役卡为**国密 CPU 卡**（M1 被 Crypto-1 破解后全行业强制迁移的结果）。官方功能清单**只有消费结算类，不含考勤门禁**——打卡机刷校园卡是考勤平台「借读」一卡通卡号数据，不是一卡通自身功能。

**背景**：由「打卡机为什么能刷校园卡」延伸到卡的完整结构调研。

**细节**：

物理结构：ISO 7810 ID-1（85.6×54×0.76mm）PVC 多层层压；Inlay 层 = 13.56MHz 蚀刻天线线圈 + 无源芯片（电感耦合供电，ISO 14443A，无电池）。

卡种类与账号规则：教工卡/学生卡/校友卡/记名卡；学生首张免费随录取通知书发放，补卡 20 元；记名卡账号 = "JM+卡号"、校友卡 = "X+卡号"。

多钱包结构（卡内至少两个独立余额）：
- 主消费钱包；
- 水控小钱包：圈存机专门开通、上限 20 元、开水补助（每月 15 元，1/3/4/5/6/9/10/11/12 月）只发这里、**换卡后资金和补助不迁移**。

两密一限（账户层防护，官方明文）：
- 查询密码（挂失/查询）与消费密码（转账/超限消费）分离，初始均为身份证后六位（末位 X 忽略）；
- 每日三时段（00:00-10:00 / 10:00-16:00 / 16:00-24:00）各设消费限额，默认 100 元，超限强制输密。

账务机制：
- 圈存确认：线上充值先进「过渡余额」，须在校内 POS 刷一下才入卡余额（脱机电子钱包对账流程）；
- 自动转账：绑定一类银行卡后余额低于 20 元自动划 50 元（可在圈存机改）。

服务入口：ecard.csu.edu.cn、微信公众号「中南大学信网中心」、企业微信「中南大学ITS」、App「中南e行」；咨询 0731-88830600 / ecard@csu.edu.cn。

**坑**：官方《校园卡服务》页面（nic.csu.edu.cn）根本不提考勤和门禁，想用一卡通官方资料研究打卡机会扑空；在打卡机视角下，这张 CPU 卡被降格为一张 UID 电子标签——卡的加密应用全程不参与，考勤机连卡的密钥都不需要。

## 国密CPU卡四层结构与高校定制边界
- 2026-09-21

**结论**：国密 CPU 卡 = ①硬件层（安全 MCU + 国密协处理器 SM1/SM2/SM3/SM4 + 物理防护）②COS 层（MF/DF/EF 文件系统 + 安全状态机 + APDU 命令）③密钥层（发卡中心主控密钥 → 一卡一密分散 → 终端 SAM 双向认证 → 会话密钥+交易计数器）④应用层（身份区/钱包区/第三方区文件）。**高校定制只发生在③④层、且在发卡环节写入**（密钥根 + 应用数据），芯片和 COS 是标准件——所谓"modify 卡"实际是"个人化发卡"。

**细节**：

密钥体系（「为什么破解不了」的三句话）：
1. 发卡中心只藏一把主控密钥（HSM/密钥管理系统里，永不出库），发卡时用卡序列号参与 SM3/SM4 运算派生出该卡专属子密钥——破一张卡推不出第二张；
2. 终端锁 SAM 卡与卡做双向挑战-应答，密钥只进不出——拆了 POS 也掏不出主密钥；
3. 交易报文全加密 + 卡内交易计数器单调递增——空中抓包无意义，重放被计数器识破。

中南定制清单：
- 实锤（官方校园卡服务页可查）：双钱包（消费+水控）、双 PIN+三时段限额、圈存确认+按月补助、卡号↔学工号映射规则；
- 推断（置信度高）：学校自有密钥根（2022 采购的国密密钥系统+加密机即为此）、应用文件布局按新中新企业规范（AID/文件 ID/密钥索引不公开）。

NFC 虚拟卡/微信二维码/人脸绑定的都是后台账户（账户层扩展），实体卡本身没变。

**坑**：两个易混点——①M1 时代的「扇区/KeyA/KeyB」概念对 CPU 卡完全不适用，CPU 卡是 COS 文件+双向认证模型；②NFC/扫码/考勤刷卡看起来都是「这张卡的事」，实际账户层和读取方式各异，卡上从未改过。
