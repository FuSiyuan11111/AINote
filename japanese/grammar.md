## 从《極楽浄土》学动词变形：命令形・使役形・假定形・可能形
- 2026-09-21

**结论**：一首歌词就能覆盖新手教材中后期才出现的多种动词活用——命令形（歌え／踊れ）、使役形（聞かせて）、ば条件（込めば）、可能否定（抜け出せない）、连用中顿（忘れ）、形容词副词形（美しく／熱く）。歌词和动漫里命令形・使役形出现极早，值得优先建立「听得出来」的语感。

**背景**：用户为日语新手，在逐词解析《極楽浄土》时集中遇到了多种动词变形，故把散落的语法点汇总成体系条目。

**细节**：

| 变形 | 歌词例 | 原形 | 意思 |
|---|---|---|---|
| 命令形 | 歌え / 踊れ | 歌う / 踊る | 唱吧！／跳吧！ |
| 使役形＋て | 聞かせて | 聞く | 让（我）听听 |
| ば 条件形 | 迷い込めば | 迷い込む | 一旦误入 |
| 可能形否定 | 抜け出せない | 抜け出す | 无法脱身 |
| 连用形中顿 | 時を忘れ | 忘れる | 忘却时间（句子中停顿） |
| 形容词副词形 | 美しく / 熱く | 美しい / 熱い | 美丽地／炽热地 |
| たい | 愛したい | 愛する | 想要爱 |
| 谦让语 | いたしましょう | する | 让我来为您效劳吧 |

各变形要点：

- **命令形**：词尾变え段（歌う→歌え、踊る→踊れ）。语气生硬，歌词中靠间投助词 や（歌えや歌え）缓冲成号召、邀约感。
- **使役形**：聞く→聞かせる「让～做」；接 て 表请求（聞かせて＝让我听听吧）。注意别和被役形 聞かされる（被迫听）搞混。
- **ば 条件形**：词尾假名变え段＋ば（込めば＝一旦～就）。
- **可能形**：抜け出す→抜け出せる「能脱身」；再＋ない＝无法脱身。
- **复合动词后缀**（新手高频）：～出す（弄出来/突然开始：走り出す「跑起来」、泣き出す「哭起来」）；～込む（深入进去：飛び込む「跳入」）；～ゆく（＝行く 作补助动词，逐渐～下去，文雅：散りゆく「凋零而去」）。
- **まま**：心のままに＝随心所欲地（まま＝照原样、任凭）。
- **～も～も**：嘘も真も無い＝谎言和真实都不存在（既…又…都…）。
- **せず**：する 的否定连用形＝不做 → 気にせず＝不顾及～（书面语）。
- **てごらん**：見る＋てごらん＝「你看看吧」，是温柔邀请而非命令。

**坑**：
- **命令形听起来凶，但语境可柔**：判断语气看语境和助词缓冲（や、な），不能只看形。
- **聞かせて（让听）≠ 聞いて（听）**：差一个使役 せ，动作方向就反转——「我听」变成「你让我听」。
- **ゆく 不是新动词**：它就是行く 的旧写法/文读（ゆきましょう＝行きましょう，前者更雅）。
- **敬语第一课**：する→いたす 是谦让语（压低自己、抬高对方），迎客语境下的 いたしましょう 就是这个用法。
- **命令形・谦让语在教材中出现很晚**，但歌词、动漫、日剧里高频出现——遇到别慌，先建立「认得出」的被动语感，产出可以以后再练。

## 从《Last (Moment)》学复句与语气：たとえ～としても・～ないで・～てみせる
- 2026-09-21

**背景**：《Last (Moment)》歌词解析中集中出现的复句、请求与决心表达，与上方《極楽浄土》条目的「动词变形」互补；词汇部分见 [lyrics.md](./lyrics.md)。

**细节**：

| 语法 | 歌词例 | 意思 |
|---|---|---|
| たとえ～としても | たとえ何を失うとしても | 即使失去一切也…… |
| ～ないで | 泣かないで | 请别哭（请求不做） |
| ～てみせる | 違えてみせる | 做给你看（赌上决心） |
| ～ため（に） | また出会うため | 为了再次相遇（目的） |
| さえ | 星の道さえ | 甚至连星辰之道都 |
| 连用形串联 | 崩れ消えゆく | 崩塌着、消失着（多层定语） |
| ず形 | 怯えず | 不害怕地（＝ない 的文言版） |

要点：

- **たとえ～（と）しても**：让步句的固定搭配。たとえ 是预告词可省略，但成对出现语气最完整；～ても（て形系）与 ～としても（原形＋）意思几乎相同。
- **～ないで**：ない形＋で，请求对方「不要做～」。
- **～てみせる**：て形＋みせる（「展示」），字面「做给你看」，实为决心宣言，强度高于单纯的意志形。
- **～ため（に）**：目的「为了～」；动词原形＋ため、名词＋のため。
- **さえ**：提示助词，举极端例子表「连～都」。
- **连用形串联**：多个动词用连用形接龙后整体修饰名词（崩れ＋消え＋ゆく記憶の世界），歌词/文学高频的压缩定语。
- **ず形**：⬆第一个例子是《極楽浄土》的 気にせず，这是第二个（怯えず）——只出现在书面语和歌词。

**坑**：
- **～ないで vs ～なくて**：ないで 带请求语气、指向人的行为；なくて 表原因/并列、指向事态，不可互换。
- **～てみせる vs ～てみる**：一字之差天壤之别——てみる＝「试试看」（尝试），てみせる＝「做给你看」（决心）。

## 从《Last (Eternity)》学让步与名词化：意志形～ようとも・～さ・～ように
- 2026-09-21

**背景**：《Last (Eternity)》歌词解析中出现的意志形（本库首次）、形容词名词化与比况表达；词汇见 [lyrics.md](./lyrics.md)，姐妹歌对照见该条目。

**细节**：

| 语法 | 歌词例 | 意思 |
|---|---|---|
| 意志形＋とも | 目覚めゆこうとも | 无论（将要）觉醒成什么…… |
| ～さ | 無意味さを知る | 知晓那份无意义（形容词→名词） |
| ～ように | 欠片のように | 像碎片一般（比况） |
| ～のは | 美しいのは君の方だった | 美丽的（那个人），曾是你 |
| だった | 君の方だった | だ 的过去「（曾经）是」 |
| ナ形容词＋に | 虚ろに朽ち果てて | 空洞地腐朽下去（ナ形容词副词化） |

要点：

- **意志形（本库首次）**：动词词尾变 おう／よう 段（行こう、食べよう、ゆこう）。单独用＝「～吧」（邀约、意志）；接 とも ＝「无论／即便要～也」，与 たとえ 配对是比 ～としても 更书面化的让步（⬆たとえ～としても）。
- **～さ**：い形容词／ナ形容词词干＋さ＝名词化「～的程度／性质」（美しさ、無意味さ）；与 ～こと／～の 的分工：さ 专门把「性质」变成可谈论的对象。
- **～ように**：名词＋のように＝「像～一样」的比况（誘うように《鳥よ》）；目的用法「为了～」已收录——居られるようにと（愿能相伴左右，《鳥よ》）。
- **～のは**：形式名词 の 把前面的词句打包成名词再接 は 主题化——「美しいのは～だ」＝「美丽的是～」。
- **だった**：だ（だ体）的过去形，です→でした；表「（当时）是」。
- **ナ形容词＋に**：ナ形容词副词化用 に（虚ろに），对照い形容词去い变く（⬆美しく／熱く）。

**坑**：
- **得る 的读音**：うる／える 皆合法（あり得る＝ありうる／ありえる），词典两收；过去形 あり得た 一般读 ありえた。
- **～ようとも 不是过去形**：长得像 た 形，其实是意志形＋とも，语气是「无论～也」；看到 たとえ 就该条件反射往让步想。

## 从《故郷に錦を飾るべし》学文语对照：べし・ぬ／ず・より・〜き
- 2026-09-22

**背景**：第三首材料是满篇文语的热血宣言曲，正好把前两首零星出现的「ず」收拢成文语体系；现代语法 ている／てくる 也出自本曲。词汇见 [lyrics.md](./lyrics.md)。

**细节**：

| 文语形态 | 歌词例 | 现代语对应 |
|---|---|---|
| べし | 飾るべし！ | ～べきだ「理应～」 |
| ぬ（否定） | 帰りはせぬ、返さぬ | ～ない |
| ませぬ | お構いしませぬ | ～ません |
| ず（否定连用） | ⬆気にせず、怯えず | ～ないで（连用修饰） |
| より（格助词） | 其の日より | ～から「自从」 |
| 〜き（文语连体形） | 熱き誇り、幼き頃 | 熱い／幼い |
| たる | 産まれ落ちたる | ～た「已然…的」 |
| ずる（サ变文语） | 信ずる | 信する |

现代语法补遗：

| 语法 | 歌词例 | 意思 |
|---|---|---|
| ～ている | 燃えている、寂れている | 「正…着／处于…状态」 |
| ～てきた | 全て置いてきた | 「（从过去）一直～到现在」 |

要点：

- **べし**：文语助动词，表当然・义务・强推量，「理应、必当」；现代对应 べき（～べきだ）。宣言、口号高频——「～べし！」自带檄文气势。
- **ぬ／ず／ませぬ**：ない 的文语全家福——ず 接连用形（気にせず、怯えず、感じず《Bad Apple!!》、できず《うたかたのせかいで》、知らず《鳥よ》），ぬ 接未然形作终止/连体（せぬ、返さぬ、戻らぬ《鳥よ》），ませぬ＝ません 的文语版。至此否定系三例集齐，见到「～ない的文言装」就能认出。
- **より**：格助词「从、自」＝から（其の日より＝自出生之日起）；现代日语的より主要只剩比较「比～」和信件落款——比较例：誰よりも近く（《竹ノ花》＝比谁都近）。
- **〜き**：文语形容词连体形——熱い→熱き、幼い→幼き、美しい→美しき；歌词/古风文本高频，看到「き结尾的形容词」先还原成い。《鳥よ》追加例：遠き、若き。
- **たる**：文语完成助动词 たり 的连体形，「已经…了的」；産まれ落ちたる其の日＝出生落地之日，比 〜た 的连体修饰更古雅。
- **信ずる**：サ变 する 的文语形 ずる（信ずる＝信する）；同族还有 存ずる＝存在する。
- **ている**：て形＋いる——「正在…」或「处于…状态」；燃えている＝燃烧着，寂れている＝（一直）萧条着。口语缩约：ている→てる（夢見てる）、ていく→てく（流れてく）、ていた→てた（掴めてた）。
- **てきた vs ていく**：时间轴上 てくる＝「（从过去）持续到说话时／朝说话人而来」，ていく＝「从现在起持续下去／离说话人而去」；置いてきた＝「一直留到现在」，⇔砕いていく＝「粉碎下去」。ゆく／いく 的文语分工另见 [confusable.md](./confusable.md)。

**坑**：
- **べし 的语气比「应该」硬**：文语 べし 斩钉截铁（「必当」），比现代 べきだ 更重。
- **其の／思ひ出 这类旧写法读音不变**：按现代音读（その／おもいで），只是字面古风。
- **帰りはせぬ 的 は**：把「帰り」名词化后用 は 提示再加 せぬ（＝しない），是「～はしない」强调句式的文语版，别当成两个分句。

## 从《Bad Apple!!》学被动与变化：流される・黒にする・白になる
- 2026-09-22

**背景**：新手两大必修语法（被动形、变化句型）在本曲集中首秀，且 黑↔白 的对仗正好演示 する／なる 之分。词汇见 [lyrics.md](./lyrics.md)。

**细节**：

| 语法 | 歌词例 | 意思 |
|---|---|---|
| 被动形（受身） | 時の隙間に流され続けて | 被时间之流冲走 |
| 被动形（受身） | 戸惑う言葉 与えられても | 即使被给予令人无措的话语 |
| ～にする | 黒にする | 把～弄成黑（人为改变） |
| ～になる | 白になる | 变成白（自发变化） |
| ～になれ | 黒になれ！ | 变黑吧！（なる的命令形） |

要点：

- **被动形（受身）**：动词变「被～」——五段动词 う段→あ段＋れる（流す→流される），一段动词 る→られる（与える→与えられる），する→される。动作承受者做主语：私が流される＝我被冲走。
- **～にする vs ～になる**：人为的「把A弄成B」用 にする（主语是施动者），自然发生的「A变成了B」用 になる。本曲 黑↔白 对仗是教科书级示例：能动手就 にする，只能承受就 になる。
- **命令形三连**：なる→なれ（黒になれ！）⬆歌え・踊れ（一段/五段）⬆成し遂げろ（サ变）——三类动词的命令形已集齐。

**坑**：
- **見えない 不是被动也不是使役**：見える 本身是可能动词「能看到」，見えない＝看不见。
- **壊す（他动）vs 壊れる（自动）**：我砸坏＝壊す；东西碎了＝壊れる。⬆同族自他对：傷つける/傷つく、落ちる/堕ちる。

## 从《Bad Apple!!》学语气词与否定强化：わ・の・なんて・だけ
- 2026-09-22

**背景**：本曲另一大宝藏是高密度的句末语气词与否定强化句式——「女性独白」的语感全靠它们。词汇见 [lyrics.md](./lyrics.md)。

**细节**：

| 语法 | 歌词例 | 意思/语感 |
|---|---|---|
| わ（句末终助词） | 見えないわ、知らないわ | 柔化断定，女性独白标志 |
| の（句末疑问） | 未来はあるの？ | 柔和的疑问「…吗？」 |
| なんて | 悲しむなんて | 「～什么的」轻蔑+意外 |
| だけ | 疲れるだけよ | 「只不过…罢了」 |
| など | 周りのことなど | 「…之类」（比なんて中性） |
| 何も～ない | 何も感じず | 什么也（不）…（全盘否定） |
| ～も～ない | 知りもしないわ | 连…都（不）…（强调否定） |
| ～こともなく | 動くこともなく | 毫不…、既不… |
| ～ばいい | 過ごせばいいの | 「～就好了」（⬆ば） |
| もし～ならば | もし私から動くのならば | 如果…的话（もし＋ならば） |

要点：

- **わ**：句末终助词，女性用语为主，让断定变柔；歌词用 わ 立刻营造女性独白感（⬆对比：極楽浄土 的 ぞ／べし 是男性宣言感）。
- **句末の**：柔和的疑问/断定（未来はあるの？）；与 ～のは（《Last (Eternity)》）的形式名词 の 同源——把句子打包成名词再收尾。
- **なんて vs など**：都表「之类」，なんて 带轻蔑或意外（「悲伤什么的，只会累」），など 中性列举。
- **だけ**：只、仅；叠 よ 成 だけよ「只不过…罢了」的叹息感。
- **否定三档强度**：普通否定（知らない）→ 全盘否定 何も～ない（什么也不）→ 强调否定 ～も～ない（连…都不，知りもしない）。
- **もし～ならば**：もし「如果」是预告词（⬆たとえ 同款机制），ならば 是 なら 的书面形。

**坑**：
- **わ 不是「我」**：句末 わ 是语气词，和代词 私/わたし 毫无关系，靠位置（句尾）区分。
- **なんて 自带情绪**：中性陈述别用 なんて，会带「不值一提」的贬低感。

## 从《うたかたのせかいで》学接续与限定：ながら・はずなのに・しか～ない・まで
- 2026-09-22

**背景**：第五首材料，愿望・限定・逆接类语法密集登场；「できずとも」让文语让步 ～とも 与《Last (Eternity)》的 ～ようとも 接上了头。词汇见 [lyrics.md](./lyrics.md)。

**细节**：

| 语法 | 歌词例 | 意思 |
|---|---|---|
| ながら | 胸を焦がしながら | 一边…一边 |
| はず | 掴めてたはず | 理应…（推断） |
| なのに | はずなのに | 明明…却（逆接） |
| しか～ない | 信じ抜くしかなかった | 只能…（限定） |
| ～たり | 捨てたりもできなくて | …之类（列举） |
| ～とも | できずとも | 即便…也（文语逆接⬆） |
| へと | 空へと続く | 向着…（へ＋と强调） |
| まで | 手が届くまで | 直到… |
| かな | 通じたかな | 「…吗」（自问） |
| できる | 捨てたりもできなくて | 能、会（する的可能形） |

要点：

- **ながら**：连用形＋ながら＝同一主语的两个动作同时进行（焦がしながら手繰り寄せた）；另有逆接用法「虽然…但」，遇到再收。
- **はず＋なのに**：はず＝据理推断「理应…」；接 のに 变成「明明本该…却（事与愿违）」——期望与现实的落差一气呵成。
- **しか～ない**：「只有/只能」，谓语必须是否定形；与 だけ 的分工见坑。
- **～たり（も）**：列举代表性动作（～たり～たり）；单个 たりも＝「就连…之类也」，带轻描淡写的委屈感。
- **～とも**：ずとも／ようとも 的 とも＝ても 的文语形，「即便…也」——⬆目覚めゆこうとも 的同一个 とも，至此两例成对。
- **へと**：へ＋と，方向感更鲜明、更文学；と 是强调帽。
- **まで**：到…为止（时间/空间/程度均可）；与起点成对：より/から⬆（起点）↔まで（终点）。
- **かな**：句末柔和自问「…吗」，男女通用（⬆わ 女性专用，かな 无性别限制）。
- **できる**：する 的可能形「能、会、做得到」；文语否定 できず、て形 できなくて＝「做不到（而…）」。

复合动词后缀补遗：

- **～抜く**：「…到底、坚持完成」（信じ抜く；同族：やり抜く、走り抜く）。
- **～合う**：「相互…」（分かり合う；同族：助け合う、話し合う）。

**坑**：
- **しか vs だけ**：しか 必须配否定（500円しかない＝只有500円），だけ 配肯定（500円だけある）；语义近似，しか 视角更「嫌少」。
- **まで vs までに**：まで＝到…为止一直持续；までに＝在…之前（截止）完成——遇到带 に 的再展开。
- **ながら 的接续**：接动词连用形（焦がし＋ながら），不是て形。

## 从《鳥よ》学文语让步家族：とも・ども・とて 与 ～ようとする
- 2026-09-22

**背景**：第六首材料文语浓度全库最高——让步（ても 系）四种形态、文语否定（ぬ・ず・えぬ・ずに）全员集结。词汇见 [lyrics.md](./lyrics.md)。

**细节**：

| 语法 | 歌词例 | 意思 |
|---|---|---|
| ～ようとする | 騙そうとしていた | 试图骗我（意志形＋とする） |
| ～とも（文语让步） | できずとも ⬆ | 即便…也 |
| ～ども（文语让步） | 探せども、問えども | 纵然寻找/追问…却 |
| ～とて（文语让步） | たとい…見えぬとて | 纵使…也 |
| ～えぬ（文语可能否定） | 忘れえぬ | 无法忘记 |
| ～ずに | 受け入れられずに | 不…而…（＝ないで） |
| けして～ない | けして二度とは見えず | 决不… |
| ～はしない | 離しはしない | 决不会…（强调否定） |
| ～すぎる | 唐突すぎる | 过于… |
| ほど | 余所余所しいほどに | 到…的程度 |
| ～限り | 見上げる限りに | 只要…（就） |
| 二度と～ない | けして二度とは見えず | 再也不 |
| ～よう（方法） | 何を知りようか | …的方法（反问「无从知晓」） |
| と（引用） | 何故お前はと問えども | 问「为何」…（引语） |
| よ（呼格） | 鳥よ | 鸟儿啊（呼唤） |

要点：

- **文语让步家族（本曲集齐）**：现代 ても → 文语 とも（前接意志形/ず形：できずとも⬆《うたかた》）→ ども（前接已然形：探せども）→ とて（たとい～とて）。意思全是「即便…也」，越往右越古；认出任意一个，整句按「即使」理解。
- **～ようとする**：意志形＋とする＝「试图做～／正要做～」；騙そう**としていた**＝当时一直想骗（⬆意志形《Last (Eternity)》）。
- **～えぬ**：连用形＋得（え）＋ぬ＝「无法…」——忘れえぬ＝无法忘记。得る⬆（あり得る）与 ぬ⬆ 的合体，文语版「できない」。
- **～ずに**：＝ないで「不…而…」；受け入れられずに＝没能接受就…（⬆泣かないで 的文语版）。
- **けして（決して）**：「决（不）」，必须搭配否定——けして～ない 是固定框架。
- **～はしない**：名词化＋は＋しない＝「…是决不会…的」（⬆帰りはせぬ《故郷に錦》的现代版）。
- **～すぎる**：词干＋すぎる＝「过于～」（唐突すぎる＝太过唐突）。
- **ほど**：～ほど＝「到…的程度」（生分到让人觉得空旷）。
- **～限り**：动词原形＋限り＝「只要…就」（見上げる限りに＝只要我还在仰望）。
- **二度と～ない**：惯用「再也不…」；⇔再び（肯定「再度」）。
- **知りよう**：连用形＋よう（様）＝「…的方法」；何を知りようか＝反问「无从知晓什么」。
- **と（引用）**：思考、发问、称呼的内容用 と 打包（「何故」**と**問う＝问「为何」）——引用助词首次登场，之后 ～と言う／～と思う 都是它。
- **よ（呼格）**：接称呼后呼唤（鳥よ＝鸟儿啊）；与句末语气词 よ（提示新信息）同形不同用。
- **思えば**：ば 形独立作「回想起来／说起来」的惯用语。
- **ように（目的）**：比况之外的目的用法如约而至——居られるようにと＝「为了能相伴左右」（と 收尾＝把心愿轻轻挂起）。

**坑**：
- **えぬ 是固定组合**：只表「无法」，见到就当文语版「できない」。
- **とて vs と（引用）形近**：たとい～とて 的 とて 是让步；～と問う 的 と 是引用——看位置。
- **お前 语体**：对上级/长辈禁用；本曲对鸟使用＝对动物的「你」自然无妨（⬆[confusable.md](./confusable.md) 人称阶梯）。

## 从《竹ノ花》学文语余绪与愿望表达：ゆ・のみ・難い・こそ・らしい
- 2026-09-23

**背景**：第七首材料，愿望祈使与文语余韵密集——ゆ・のみ・難い 补上文语拼图最后几块，こそ・らしい 是口语高频新点。词汇见 [lyrics.md](./lyrics.md)。

**细节**：

| 语法 | 歌词例 | 意思 |
|---|---|---|
| ～ゆ（文语） | 見ゆる、消ゆる | ＝見える／消える（文语下二段） |
| のみ（文语） | 消ゆるのみ | ＝だけ「仅仅」 |
| ～難い（がたい） | 換え難く | 难以～ |
| ～らしい | 自分らしく | 像…的样子、有…的风范 |
| こそ | だからこそ | 正是…（强调） |
| 生きよ（文语命令） | その身だからこそ生きよ | 活下去吧 |
| が（逆接） | 願ったが | 虽然…但 |
| それでも | それでも儚く消ゆるのみ | 即便如此仍… |
| いつまでも | いつまでも疼いている | 无论到何时、始终 |
| せめて | せめて自分らしく | 至少、哪怕 |
| 未だ～ぬ | 未だ咲かぬ | 尚未… |
| より（比较） | 誰よりも近く | 比谁都… |
| でなく | 誰にでなく | ＝ではない「不是」 |

要点：

- **ゆ（見ゆ・消ゆ）**：文语把「可能/自发」压成短形——見ゆる＝見える、消ゆる＝消える；⬆見えない・消えゆく 的文语兄弟，古风歌词高频。
- **のみ**：文语限定「仅、只」＝だけ；消ゆるのみ＝只是消逝（⬆だけ《Bad Apple!!》）。
- **～難い（がたい）**：连用形＋難い＝「难以～」（換え難い、信じがたい）；比 ～にくい 更书面，且偏「本性上难以」。
- **～らしい**：名词＋らしい＝「有…应有的样子」——自分らしい＝活出自我。
- **こそ**：提示助词，把前面的词推上聚光灯——だからこそ＝「正因为如此才…」。
- **文语命令形 よ**：一段动词命令形现代 ろ（生きろ）、文语 よ（生きよ）；歌词、古风文本用 よ。
- **が（逆接）**：句中 が＝「虽然…但」（願ったが…）；与主语 が⬆ 同形不同用，看位置。
- **も～なければ（列挙）**：AもなければBもない＝「既没有A也没有B」；本曲＝（爱）也未必就是一切。
- **それでも／いつまでも／せめて**：愿望句三大副词——「即便如此」「永远」「至少」，祈愿文体的骨架。
- **未だ～ぬ**：文语惯用「尚未…」＝まだ～ない。
- **より（比较）**：⬆文语「从」之外的比较用法登场——誰よりも＝比谁都；誰より／何より 高频。

**坑**：
- **らしい ≠ みたい**：らしい＝「符合…特质」（子供らしい＝有孩子样），みたい＝「像…（未必是）」。
- **こそ 紧跟被强调词**：だから**こそ**、君**こそ**——挪位意思就散。
- **が 的三种身份**：主语（私が⬆）、逆接接续（願ったが）、句末柔和收尾（～ですが）——靠位置区分。

## 从《With the rain that never stops》学口语引用与心境语法：って・てしまう・んだ・けど
- 2026-09-23

**背景**：首篇用户自创歌词，现代口语浓度全库最高——って・てしまう・んだ・けど 等口语骨架词一次到位。词汇见 [lyrics.md](./lyrics.md)。

**细节**：

| 语法 | 歌词例 | 意思 |
|---|---|---|
| って（口语引用） | 降り続ければいいって | ＝と「（心里）想着…」 |
| ～てしまう | 捨ててしまいたかった | 好想统统丢掉（完了/遗憾） |
| ～たりもする | 本気で考えたりもした | 甚至想过（之类） |
| ～気がする | 責められている気がして | 总觉得被指责 |
| ～ようだ | 言われてるようで | 仿佛被说成那样 |
| ～たところで | 消えたところで | 即使消失也（徒劳） |
| ～やしない | 気にも留めやしない | 根本不会放在心上 |
| んだ（のだ） | 生きてきたんだ | （解释）就是…啊 |
| けど／だけど | 逃げだしたいけど | 虽然…不过 |
| ～なくても | 止まなくても | 即使不…也 |

要点：

- **って**：と 的口语版——引用想法、传闻；写作 と，说话/歌词 って（⬆と 引用《鳥よ》）。
- **～てしまう**：两面——①完了・彻底（「食べてしまった」＝（不知不觉）吃完了）②遗憾・懊悔（忘れてしまった＝忘了，糟了）；＋たい＝てしまいたい「好想一了百了」。本曲两面同框：壊してしまいたかった。
- **～たりもする**：⬆たり 列举＋も＝「甚至也想过…」，自嘲常客（考えたりもした）。
- **～気がする**：「总觉得～」，证据不足的主观感觉；⬆気 家族（気にせず・気に留める）。
- **～ようだ**：ように（⬆比况/目的）的断定形兄弟——「仿佛是…」；ようで＝そのて形（ようで苦しい＝仿佛…而痛苦）。
- **～たところで**：消极让步「即使…也（没用）」；消えたところで…留めやしない＝即使消失也没人在意。⬆ところ 的语法化。
- **～やしない**：～はしない（⬆鳥よ 離しはしない）的更口语版，「根本不会…」。
- **んだ／のだ**：句尾解释「（是这么回事）啊」；生きてきた**んだ**＝（我）就是这么活过来的；与句末 の⬆ 同源（のだ→んだ）。
- **けど／だけど**：が 逆接（⬆竹ノ花 願ったが）的口语版；也可只做话头缓冲（「けど…」后半句吞掉）。
- **～なくても**：ない＋ても＝「即使不…也」；止ま**なくても**・見え**なくても** 双连——「就算雨不停、就算看不见前方」。

**坑**：
- **てしまう 的语感看语境**：「疲れてしまった」是遗憾；「食べてしまった」可能只是「（不知不觉）吃完了」——没有后悔就别硬译「糟了」。
- **んだ 不要滥用**：んだ 是对已知信息的解释；纯新信息陈述别加（「雨だ」≠「雨なんだ」的微妙差别）。
- **やしない 偏粗**：男性口语、情绪强；礼貌场合用 ～はしません／全然～ない。

## 从《play back your memory》补齐基础口语：たら・じゃない・ね・よ
- 2026-09-23

**背景**：第九首材料（用户自创），把新手最基础却一直未登场的四个口语件补齐——至此条件句「四天王」集其三，句末语气词 ね／よ 就位。词汇见 [lyrics.md](./lyrics.md)。

**细节**：

| 语法 | 歌词例 | 意思 |
|---|---|---|
| ～たら | 歌ってたらキミが笑ってた | 唱着唱着（就发现）… |
| じゃない | 1人じゃない | 不是一个人 |
| ね（句末） | 辛いね、キミね | 呢、吧（寻求共鸣） |
| よ（句末） | まだいるよ | 哦（断定告知） |

要点：

- **～たら**：た 形＋ら＝「如果…／一…就…」；重「先后相继」（唱着唱着**就**发现了）。条件句至此集齐三个：ば⬆（一般条件）、なら⬆（既定前提）、たら★（先后相继）——第四员 と（自然必然）尚未登场，出现即收。てたら＝ていたら 的缩约（⬆ている 缩约家族：てる・てく・てた・てたら）。
- **じゃない**：ではない 的口语缩约＝「不是～」；名词・ナ形容词直连（1人**じゃない**）。另有反问用法「～じゃない？」＝「不是…吗（其实是啊）」，出现再收。
- **ね**：句末寻求认同「呢、吧」——把对方拉进同一感受（辛い**ね**、キミ**ね**）。
- **よ**：句末断定告知「哦」——把对方可能不知道的信息推过去（まだいる**よ**）。⬆呼格 よ《鳥よ》（鳥よ＝呼唤）同形不同用，靠位置区分。

**坑**：
- **ね vs よ**：「いいね」（真好啊——共享你的感受）vs「いいよ」（可以哦——给你许可）；一个拉近距离，一个单向输出。
- **たら vs ば**：たら 重先后发生，ば 重一般条件；歌词里常互换，初学先认出「都是如果」即可。
- **じゃない 有反问脸**：单独上扬（～じゃない？）是「难道不是吗」，跟平调否定「不是」完全两回事。
