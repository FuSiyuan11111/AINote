# 日语学习域 · 总结规范

本文件是根目录 [README](../README.md) 在日语学习域的**补充约定**：根 README 管通用流程（先读后写、锚点目录、倒金字塔、去重合并），本文件只记录学习场景下的特化规则。两者不冲突——根规范是骨架，本文件是特化。

## 用户与学习方式
- 用户是日语新手（词汇量低），通过逐词解析句子、歌词来学习；
- **细节优先，不要概括**：条目可省略「结论」段；压缩寒暄与过程，但保留全部词汇、读音、词性、释义和语法讲解（2026-09-21 用户明确反馈）。

## 解析交付方式（默认工作流，2026-09-21 起生效）
- 用户发来日语文本且**无特殊说明**时：直接解析并写入对应文件（歌词→`lyrics.md`；语法新点→`grammar.md`；近似对比→`confusable.md`），对话框只给**简短回执**——写入位置、新增/合并了哪些词条与语法点、值得注意的坑；
- **不**在对话框重发完整解析；用户明确要求当面讲解时才展开；
- 已学过的词不重复开词条，改为在文件内交叉引用（⬆ 标记或链接）。

## 条目格式微调
- 「细节」区允许（且鼓励）用表格组织：
  - 词汇表：词｜读音｜词性｜释义；
  - 语法变形表：变形｜例词｜原形｜意思；
- 「坑」区保留，收易错点（多音字、自动词/他动词、书写语感等）；
- 「背景」可简写，交代材料来源与用户水平即可。

## 引用约定（歌词类）
- **第三方歌词**：只保留词级片段，用作分段锚点和例词；不整段复制进笔记（兼顾版权与按词检索）；
- **用户自创歌词**（2026-09-23 起默认）：视为用户本人的作品，**表格即歌词**——按分段把歌词逐词按序写入表格，读表自上而下即全文，表格外不另录原文；有分析价值的词正常分析，已学词/助词只标读音与 ⬆，连续无价值词合并一行，整句重复只占一行标 ⬆；
- 条目须**自含语法标注**：行内「标注」列（⬆已学／★新）＋每段末「语法」行提炼；完整体系仍汇总于 grammar.md；
- 默认按自创处理；用户特殊说明为第三方的，按第三方规则执行。

## 目录组织
- `lyrics.md`：歌词词汇精读，**一首歌一个条目**，按场景分段收词；
- `grammar.md`：语法点条目，可跨材料汇总；条目过多时按主题拆分（如动词变形、助词、敬语各一文件）；
- `confusable.md`：近似辨析，收录「极其相像但有细微差别」的对比组——近义词、自他动词对、同字异读、同形语法；**一组一条**，再次遇到时合并更新而非新增；
- 同一材料再次学习 → 先读后写、合并进已有条目；新材料 → 末尾追加新条目并同步锚点目录。
